## 🍽️ Menu Master

**Menu Master** es una plataforma SaaS enfocada en digitalizar los menús de negocios y facilitar su publicación online.

### ✨ Características

* 🎨 Editor visual de menús.
* 📱 Diseño responsive.
* 🌐 Publicación mediante enlaces.
* ☁️ Subida y administración de imágenes.
* 👤 Gestión de usuarios.
* 🏪 Administración de negocios.
* 💳 Planes y funcionalidades Premium.
* 🔗 Menús públicos.
* 📊 Arquitectura preparada para crecimiento.
